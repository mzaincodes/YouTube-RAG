# Assets

Screenshots referenced by the root [`README.md`](../README.md) live here.

Expected filenames:

| File | Shows |
|------|-------|
| `screenshot-chat.png` | Main chat area — a streamed answer with expanded source citations |
| `screenshot-sidebar.png` | Sidebar — URL input, indexed video library and database statistics |

To capture them: run `streamlit run app.py`, index a video, ask a question,
then screenshot the browser window and save the files here with those names.
